Veril es un arrecife mixto de aproximadamente **20 galones (75 litros)**, pensado para mantener peces, corales e invertebrados en una urna AIO artesanal.

La documentación explica cómo se está montando, ciclando, madurando y manteniendo el acuario. También recoge el hardware utilizado, los organismos previstos y la evolución del sistema.

Los prefijos numéricos orientan la lectura. Cada apartado enlaza con la información más concreta cuando es necesario.
