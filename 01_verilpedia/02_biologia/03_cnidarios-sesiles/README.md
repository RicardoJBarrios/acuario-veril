# Cnidarios sésiles

Esta categoría reúne organismos sésiles o principalmente sésiles del filo Cnidaria que pueden formar parte de un acuario de arrecife. Incluye corales, gorgonias, anémonas, coralimorfarios, zoántidos y otros organismos coraliformes.

## Responsabilidad documental

Las fichas describen identidad, función, necesidades generales, crecimiento, agresividad, compatibilidad y límites de interpretación. Las decisiones concretas de selección y colocación se documentan en la [implementación de Veril](../../../02_configuracion/README.md) y en las dimensiones correspondientes.
