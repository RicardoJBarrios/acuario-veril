# Corales LPS

Fichas generales de corales de pólipo grande. El acrónimo describe una agrupación práctica y no determina por sí solo las necesidades de cada género o especie.

## Extensión de pólipos y síntomas

La extensión o inflación de un LPS varía con el ciclo diario, flujo,
alimentación, aclimatación y estado del tejido. Que una colonia permanezca
menos inflada puede servir como aviso para revisar el entorno, pero no señala
por sí sola una alteración de KH, salinidad o nutrientes. Comparar la pieza
consigo misma y revisar flujo, detrito, contacto, temperatura, salinidad y
mediciones del agua antes de atribuir una causa. Véase el [plan de observación
biológica de corales](../../../../../03_pendientes/maduracion/plan-indicadores-visuales-corales.md).
