# Corales SPS

Fichas generales de corales de pólipo pequeño. La agrupación resume necesidades habituales de estructura y estabilidad, pero cada género requiere una lectura individual.

## Crecimiento y signos visibles

El borde de crecimiento, las puntas, la extensión de pólipos y la continuidad
del tejido sirven para seguir la evolución de una colonia mediante
observaciones comparables. La detención aparente del crecimiento, las puntas
blancas, la recesión o el blanqueamiento no identifican por sí solos una falta
de KH, Ca, Mg, nutrientes o trazas.

Ante un cambio persistente se contrastarán primero las mediciones disponibles
de alcalinidad y calcio con su tendencia, y se revisarán también nutrientes,
PAR, flujo, temperatura, salinidad, aclimatación, lesiones y plagas. La
precipitación o la dificultad anómala para mantener Ca/KH puede motivar una
medición de Mg, pero no demuestra que sea la causa. El término «puntas
quemadas» describe un aspecto; no confirma un diagnóstico de alcalinidad.

Los cambios de color vinculados a I, K, Fe u otros trazas no son una base
suficiente para dosificar. Las correlaciones visuales deben tratarse como
hipótesis y contrastarse con mediciones independientes.

El [plan de observación biológica de corales](../../../../../03_pendientes/maduracion/plan-indicadores-visuales-corales.md)
describe cómo usar estos cambios como avisos de medición en Veril, sin
considerar los SPS como centinelas iniciales.
