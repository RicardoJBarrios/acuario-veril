# Nephthea

![Nephthya sp.](https://commons.wikimedia.org/wiki/Special:FilePath/Nephthya%20sp.%20%28Soft%20tree%20coral%29.jpg)

**Fuente de imagen:** [Wikimedia Commons, *Nephthya* sp.](https://commons.wikimedia.org/wiki/File:Nephthya_sp._(Soft_tree_coral).jpg)

## Qué es

**Nephthea** se usa en acuariofilia para blandos arborescentes tipo soft tree coral. En comercio el nombre puede mezclarse con *Nephthya*, *Litophyton*, *Capnella* u otros octocorales de aspecto parecido, así que la ficha debe leerse como grupo práctico hasta confirmar identificación.

Para Veril queda como condicional. Es un blando arborescente que requiere espacio suficiente y validación de la especie concreta.

## Lectura rápida

- **Grupo**: Coral blando arborescente
- **Dificultad**: Media por identificación y adaptación
- **Tamaño / crecimiento**: Medio; variable según especie
- **Luz**: Media si es fotosintético
- **Flujo**: Moderado e indirecto
- **Alimentación**: Principalmente fotosintético si corresponde al grupo comercial habitual; confirmar
- **Agresividad / riesgo**: Identificación dudosa, sombreado, alelopatía y crecimiento arborescente
- **Apto para nano**: Posible con pieza pequeña y soporte separable
- **Apto para principiantes**: Mejor no como primer blando

## Biología y comportamiento

La clasificación práctica para esta ficha es:

| Categoría | Valor |
| --- | --- |
| Reino | Animalia |
| Filo | Cnidaria |
| Clase | Anthozoa |
| Subclase | Octocorallia |
| Orden | Malacalcyonacea |
| Grupo práctico | Coral blando arborescente |
| Género comercial | *Nephthea* / *Nephthya* |

La transcripción lo describe como un árbol de Kenia más raro, bonito, de crecimiento lento y menos invasivo. Esa lectura puede ser útil, pero no elimina la necesidad de confirmar que se trata de un blando fotosintético manejable y no de un octocoral no fotosintético.

Los valores generales de Veril no demuestran tolerancia de la especie. `Sin intervalo cuantitativo específico localizado` indica falta de evidencia publicada/revisada, no ausencia de necesidad de control.

## Requisitos de mantenimiento
- **Ubicación**: Zona baja-media o media con margen lateral
- **Soporte**: Base separable para poder recolocar
- **Luz**: Media si el ejemplar es fotosintético
- **Flujo**: Moderado, ancho e indirecto
- **Temperatura**: 24-26 °C
- **Salinidad**: 1.024-1.026
- **pH**: 8.0-8.4
- **Nutrientes**: Detectables y estables
- **Mantenimiento**: Observar contracción persistente, necrosis basal y sombreado

## Compatibilidad y riesgos

El riesgo principal es comprarlo por nombre común sin confirmar comportamiento real. Si es un blando fotosintético arborescente, puede funcionar con cuidados parecidos a otros blandos. Si no lo es, puede requerir alimentación fina y estabilidad que no encajan con Veril.

Riesgos concretos:

- Identificación comercial imprecisa
- Sombreado cuando crece
- Alelopatía junto a otros blandos
- Pérdida de tejido si llega mal adaptado
- Confundirlo con especies no fotosintéticas

No hay entrada de catálogo vinculada en la revisión previa de **Elite Reef Kanarias**. Debe buscarse como *Nephthea*, *Nephthya*, soft tree coral o blando arborescente similar.

- Confirmar identificación real
- Confirmar si es fotosintético
- Confirmar tamaño abierto y soporte
- Confirmar que no viene con necrosis basal
- Confirmar que no se confunde con gorgonia u octocoral NPS
