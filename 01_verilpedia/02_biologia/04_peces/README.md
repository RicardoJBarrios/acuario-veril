# Peces

Esta categoría reúne las fichas generales y específicas de peces marinos relevantes para acuarios de arrecife.

## Responsabilidad documental

Las fichas describen comportamiento, tamaño adulto, alimentación, territorio, compatibilidad, necesidades de espacio y carga biológica. La población concreta, el orden de incorporación y la aceptación en Veril se documentan fuera de esta categoría.
