# Plantilla de parámetros de mantenimiento medibles

Usar esta matriz en todas las fichas individuales de mantenimiento de
cnidarios, peces, invertebrados y algas. Adaptar los campos a su biología: los
parámetros no aplicables se marcan como tales y se justifican. No dejar celdas
vacías ni sustituir magnitudes por adjetivos. No es una plantilla para fichas
de enfermedades, plagas, panorámicas de grupos ni microorganismos oportunistas.

## Parámetros de mantenimiento medibles

| Parámetro | Rango o condición cuantificada | Unidad / escala | Alcance y evidencia |
| --- | --- | --- | --- |
| Temperatura | | °C | Distinguir intervalo de la especie, referencia de grupo y compatibilidad con Veril |
| Salinidad | | `S_P` u otra escala explícita | No intercambiar `S_P`, ppt, g/kg ni gravedad específica sin declarar la conversión |
| pH | | escala de pH declarada si se conoce | Indicar rango y fuente; no usar «estable» como valor |
| Luz | | PAR/PPFD: µmol fotones m⁻² s⁻¹ | Para organismos fotosintéticos, rango y fuente. En Veril medir la posición real bajo el agua con el DanoPlus DP-414; una consigna porcentual de luminaria no sustituye el PAR |
| Fotoperiodo | | h/día | Rango respaldado por fuente; si no existe, consignar la ausencia de referencia cuantitativa |
| Flujo | | cm/s, cm/s de velocidad local u otra magnitud definida | Usar rango cuantitativo si la fuente lo publica. No convertir «bajo/medio/alto», caudal de bomba ni renovaciones por hora en velocidad local sin método y geometría |
| Espacio / tamaño | | L, cm o cm² según corresponda | En animales móviles, registrar volumen mínimo y dimensiones si una fuente los establece. En organismos sésiles, priorizar tamaño adulto/colonia y separación espacial; no inventar un volumen mínimo universal |
| Química específica | | unidad SI o de acuario indicada | Añadir solo parámetros críticos para el organismo (p. ej., alcalinidad, calcio o magnesio) y sus rangos numéricos respaldados |
| Alimentación | | tamaño de presa, masa, frecuencia u otra unidad | Para organismos heterótrofos, indicar tipo y pauta cuantificada solo si la fuente la respalda; no convertir «alimentar a menudo» en frecuencia inventada |

### Reglas para completar la matriz

- **Especie:** priorizar mediciones o recomendaciones publicadas para la especie y sus condiciones. Anotar identidad taxonómica incierta cuando cambie los requisitos.
- **Grupo:** si solo existe un rango de acuariofilia para un género o grupo funcional, declararlo expresamente como referencia de grupo, no como umbral fisiológico específico.
- **Veril:** la envolvente del sistema se puede consignar como criterio de compatibilidad local, nunca como tolerancia demostrada del organismo. La referencia térmica vigente es 25–26 °C preferida y 24–27,5 °C aceptable; la salinidad objetivo es `S_P = 35` y el intervalo orientativo general de pH de arrecife es 8,0–8,4. Consultar la configuración vigente antes de reutilizar estos datos.
- **Sin dato:** escribir `Sin rango cuantitativo específico localizado` y especificar qué medición local permitiría describir las condiciones de Veril. Añadir una referencia numérica de grupo o de compatibilidad solo si está documentada, separándola claramente del valor específico ausente. No completar el hueco con una cifra deducida de la categoría comercial.
- **No aplica:** escribir `No aplica` y explicar la causa biológica; no asignar cero como si fuese un valor fisiológico.
- **Medición local:** identificar instrumento, punto de medición, condiciones y límites. Para PAR, medir donde estaría el organismo, a su altura y orientación, con el DanoPlus DP-414 sumergido; documentar incertidumbre y espectro.
- **Mínimo de acuario:** aceptar litros solo si una fuente los relaciona con el organismo y explica el criterio. Si el dato no es pertinente (p. ej., un coral sésil), consignar `No existe mínimo universal en L` y sustituirlo por las necesidades espaciales pertinentes.
