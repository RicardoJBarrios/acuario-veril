# Alpheus armatus

**Imagen:** [Wikimedia Commons, *Alpheus armatus*](https://commons.wikimedia.org/wiki/File:Alpheus_armatus.jpg)

## Qué es

**Alpheus armatus** es una gamba pistola del Caribe asociada en la naturaleza a anémonas, especialmente del género *Bartholomea*. No cumple el mismo papel práctico que una gamba pistola pequeña para escena gobio-gamba.

Para Veril queda como no propuesto. La ficha existe para no mezclarla con [*Alpheus randalli*](alpheus-randalli.md), que sí representa mejor la escena gobio-gamba documentada para nanos.

## Lectura rápida

- **Grupo**: Gamba pistola asociada a anémona
- **Dificultad**: Media
- **Tamaño / crecimiento**: Confirmar ejemplar
- **Función**: Relación simbiótica específica, no limpieza básica
- **Alimentación**: Omnívora/carnívora oportunista
- **Riesgo principal**: Exigir una escena con anémona que Veril no plantea
- **Apto para nano**: Solo con diseño específico
- **Apto para principiantes**: No como compra general

## Biología y comportamiento

La clasificación práctica para esta ficha es:

| Categoría | Valor |
| --- | --- |
| Reino | Animalia |
| Filo | Arthropoda |
| Clase | Malacostraca |
| Orden | Decapoda |
| Grupo práctico | Gamba pistola |

Como otros alfeidos, puede excavar, defender refugio y producir chasquidos con la pinza. La diferencia importante para Veril es su asociación con anémonas, no con gobios de madriguera como eje práctico.

## Requisitos de mantenimiento

- **Refugio**: Estructura estable y zona baja segura
- **Compañero**: No asumir que sustituye a una gamba pistola de gobio
- **Alimentación**: Comida fina/carnosa que llegue al refugio
- **Aclimatación**: Lenta y sin cobre
- **Diseño**: Solo si se acepta una escena específica con anémona compatible

## Compatibilidad y riesgos

El riesgo está en forzar un animal atractivo dentro de un diseño que no lo necesita. Si se añade por confusión con otras gambas pistola, puede condicionar arena, roca y fauna sin aportar la simbiosis esperada.
