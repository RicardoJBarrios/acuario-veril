# Babylonia

**Imagen:** [Wikimedia Commons, *Babylonia formosae*](https://commons.wikimedia.org/wiki/File:Babylonia_formosae_01.jpg)

## Qué es

**Babylonia** agrupa caracoles marinos carnívoros de arena. En las fuentes recientes aparece **Babylonia formosae** como caracol que remueve el sustrato, y en el README ya se venía citando **Babylonia zeylanica** como comparación.

Para Veril quedan como no propuesto. No son equivalentes funcionales a *Nassarius* pequeños: pueden remover arena, pero su lectura de mantenimiento es la de caracoles carnívoros de mayor escala.

## Lectura rápida

- **Grupo**: Caracol carnívoro de arena
- **Dificultad**: Media
- **Tamaño / crecimiento**: Medio, según especie
- **Función**: Remoción de arena y consumo de alimento carnoso
- **Alimentación**: Carnívora/carroñera
- **Riesgo principal**: Confundirlo con *Nassarius* y sobredimensionar la fauna de arena
- **Apto para nano**: No como equipo básico
- **Apto para principiantes**: No como sustituto de caracoles pequeños

## Biología y comportamiento

La clasificación práctica para esta ficha es:

| Categoría | Valor |
| --- | --- |
| Reino | Animalia |
| Filo | Mollusca |
| Clase | Gastropoda |
| Grupo práctico | Caracol carnívoro de arena |

Estos caracoles usan una probóscide para buscar alimento en el sustrato. Esa conducta puede ayudar a remover arena, pero no los convierte en pastadores de algas ni en una versión grande de *Nassarius*.

## Requisitos de mantenimiento

- **Arena**: Zona útil para desplazarse
- **Alimentación**: Alimento carnoso suficiente
- **Número**: Muy prudente; no aplicar ratios de *Nassarius*
- **Aclimatación**: Lenta
- **Cobre**: No tolera medicación con cobre

## Compatibilidad y riesgos

El riesgo documental principal es de identificación funcional. Si se compra como "limpiador de arena", puede terminar siendo un caracol carnívoro que exige alimentación y no resuelve algas.

Riesgos concretos:

- Hambre si no recibe alimento carnoso
- Competencia con *Nassarius* y otros detritívoros
- Tamaño desproporcionado para la arena de Veril
- Lectura equivocada como caracol herbívoro o detritívoro fino
