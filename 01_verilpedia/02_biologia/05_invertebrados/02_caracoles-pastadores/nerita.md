# Nerita

**Imagen:** [Wikimedia Commons, *Nerita versicolor*](<https://commons.wikimedia.org/wiki/File:Nerita_versicolor_%28four-toothed_nerite_snails%29_Bahamas.jpg>)

## Qué es

**Nerita** agrupa caracoles pastadores de zonas rocosas intermareales y arrecife. En comercio pueden aparecer como neritas o "neritinas" marinas, aunque ese nombre común se mezcla con especies de agua dulce o salobre.

Para Veril son condicionales. Pueden pastar algas y biofilm, pero hay que confirmar que sean especies marinas de arrecife y aceptar su tendencia a explorar bordes y salir del agua si el acuario lo permite.

## Lectura rápida

- **Grupo**: Caracol pastador
- **Dificultad**: Baja a media
- **Tamaño / crecimiento**: Pequeño a medio
- **Función**: Biofilm y algas finas sobre roca y cristal
- **Alimentación**: Herbívoro raspador
- **Riesgo principal**: Escape, identificación comercial imprecisa y falta de alimento
- **Apto para nano**: Posible
- **Apto para principiantes**: Sí, si se valida especie marina y tapa/borde

## Biología y comportamiento

La clasificación práctica para esta ficha es:

| Categoría | Valor |
| --- | --- |
| Reino | Animalia |
| Filo | Mollusca |
| Clase | Gastropoda |
| Grupo práctico | Caracol pastador |

Las neritas son caracoles robustos de superficies duras. En acuario pueden complementar a *Trochus*, *Astraea* o *Turbo* porque aprovechan película vegetal y algas finas en zonas distintas.

La transcripción las menciona dentro del grupo práctico recomendado para empezar junto a *Turbo* y *Nassarius*. Para Veril ese dato no las convierte en compra automática: antes hay que confirmar especie, salinidad de mantenimiento y riesgo de escape.

No prueban que el organismo tolere todo el intervalo ni sustituyen sus requisitos publicados. `Sin intervalo cuantitativo específico localizado` identifica una laguna documental, no una recomendación para mantener el organismo sin control.

## Requisitos de mantenimiento

- **Volumen**: Compatible con nano
- **Temperatura**: 24-26 °C si se trata de especie tropical de arrecife
- **Salinidad**: 1.024-1.026 Para ejemplares marinos
- **pH**: 8.0-8.4
- **Alimentación**: Biofilm, diatomea y algas finas
- **Acuario**: Bordes controlados si hay tendencia a salir
- **Aclimatación**: Lenta, especialmente si vienen de baja salinidad
- **Cobre**: No toleran medicación con cobre

## Compatibilidad y riesgos

Suelen ser compatibles con arrecife. El problema práctico es comprar una nerita mantenida en baja salinidad o una especie que no corresponda al uso marino esperado.

Riesgos concretos:

- Salir del acuario
- Morir por aclimatación brusca desde baja salinidad
- Falta de alimento vegetal
- Confusión con neritinas de agua dulce o salobre
- Presión de ermitaños si faltan conchas

## Variantes comerciales observadas

No hay variante activa vinculada para Veril. La transcripción usa el nombre común "Neritina" para el contexto marino; debe validarse la identificación real antes de tratarla como *Nerita* apta para arrecife.
