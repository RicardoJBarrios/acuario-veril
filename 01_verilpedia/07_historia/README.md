# Historia de la acuariofilia marina

Esta sección reúne, como investigación personal de apoyo, el origen, la evolución y el uso histórico de métodos, arquitecturas y conceptos relevantes para la acuariofilia marina. No pretende ser una historia académica completa ni una autoridad sobre las atribuciones discutidas.

Las fichas históricas aportan contexto y no sustituyen a las dimensiones arquitectónicas, las fichas de organismos, los parámetros ni los documentos de implementación de Veril.
