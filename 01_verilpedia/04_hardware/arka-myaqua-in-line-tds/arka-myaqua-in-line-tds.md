# ARKA myAQUA In-Line TDS Meter (TDSIL)

## Identificación

| Campo | Dato |
| --- | --- |
| Fabricante | ARKA Biotechnologie GmbH |
| Marca/línea | ARKA myAQUA |
| Producto | In-Line TDS Meter (medidor TDS en línea) |
| Referencia | TDSIL |
| Función | Lectura en línea del TDS indicado en agua |

El fabricante describe el equipo como un medidor para determinar TDS de forma continua en circuitos de ósmosis inversa. No es una sonda de conductividad ni un medidor portátil de inmersión.

## Especificaciones publicadas

| Parámetro | Dato declarado |
| --- | --- |
| Intervalo TDS | 0–999 ppm |
| Exactitud declarada | ±2 % |
| Temperatura de operación | 0–50 °C |
| Consumo | 2,5 mA |
| Consumo en espera | 100 μA |
| Conexión | Racores de 1/4 pulgadas; se anuncian adaptadores de 3/8 pulgadas |

La página del fabricante no declara en su resumen consultado el método o factor de conversión usado para expresar TDS, resolución, calibración ni compensación de temperatura. La cifra mostrada se registrará como TDS indicado por este instrumento y no como medida directa de cada sustancia disuelta.

## Uso y límites

El equipo se conecta a una línea de agua mediante sus adaptadores. La ubicación exacta, su relación con el monitor HM Digital TRM-1 y su uso en el circuito de Veril no quedan definidos por esta ficha. La instalación y la lectura real requieren comprobar el manual y la configuración física.

La ficha del fabricante describe el equipo como apto para monitorización permanente. Eso no convierte una lectura en validación de pureza química o microbiológica ni demuestra el rendimiento del RO/DI de Veril.
