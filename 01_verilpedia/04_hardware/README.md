# Hardware de Veril

La urna a medida y las fichas de hardware utilizadas por Veril se documentan
en este repositorio como una recopilación personal de especificaciones,
observaciones y referencias. No es documentación oficial del fabricante ni
una validación técnica independiente. Las decisiones de selección, instalación
y aceptación pertenecen a `02_configuracion/`, a los planes y a las operaciones fechadas

## Urna

- [Urna de Veril](urna/README.md): fabricación, display y compartimento técnico
