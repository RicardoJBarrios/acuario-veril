## Aplicación prevista

El tubo se utilizará para interconectar el RO6CB, las carcasas T33, el monitor TDS, el manómetro, el desagüe y los depósitos cuando se defina el montaje. La compatibilidad de cada conexión, el corte limpio y la retención del tubo se comprobarán antes de presurizar.

La longitud disponible no implica que todo el tubo deba instalarse. Se reservará la longitud necesaria para inspección, mantenimiento y aislamiento de cada componente.
