# Diagnóstico y bioseguridad

Este índice reúne fichas transversales para interpretar crecimientos, lesiones, organismos acompañantes y enfermedades posibles en un acuario marino. No convierte una observación visual en un diagnóstico y no sustituye la consulta de fuentes competentes.

## Cómo leer las fichas

Las etiquetas de nivel expresan prioridad de observación, no una medida clínica. «Normal» describe una posibilidad compatible con la sucesión de un sistema; «oportunista» describe un organismo que puede aumentar bajo determinadas condiciones; «plaga» describe un riesgo de expansión o daño; «síndrome» describe un patrón; y «enfermedad» requiere una causa respaldada por evidencia.

Las fichas separan hechos generales, práctica habitual de la afición, inferencias y decisiones de Veril. Cuando una afirmación depende de la especie, la cepa, el método de medición o el ejemplar, se mantiene como condicional.

## Alcance

La clasificación «normal», «oportunista», «plaga», «síndrome» o «enfermedad» es una hipótesis de trabajo. Un organismo visible no se considera perjudicial solo por aparecer. La aplicación concreta a Veril se enlaza desde la [configuración biológica](../../../02_configuracion/03_biologia/README.md) y los planes de [maduración](../../../03_pendientes/maduracion/README.md), mientras que las actuaciones ejecutadas pertenecen a [Operaciones](../../../04_operaciones/README.md).
