# Salifert pH Profi Test

## Identificación y estado

| Campo | Dato |
| --- | --- |
| Marca y producto | Salifert pH Profi Test |
| Método | Indicador colorimétrico y carta visual de alta gama |
| Estado en Veril | Candidato pendiente de compra |
| Capacidad | Aproximadamente 50 pruebas según fabricante |

## Rango y lectura

El fabricante declara **pH 7,4–8,6** y que el kit permite seguir fluctuaciones de aproximadamente **0,2 unidades de pH**. La resolución de la carta no debe leerse como exactitud certificada. La prueba es adecuada para agua marina; seguir el volumen, número de gotas, espera y forma de comparación que indique el manual vigente. No inferir un valor fuera del rango a partir de un color saturado.

## Encaje previsto en Veril

Se propone para la línea base antes del ciclado e investigar oscilaciones mediante muestras puntuales. No ofrece seguimiento continuo ni registra el ciclo diario. Para interpretar una lectura deben considerarse hora, aireación/intercambio gaseoso, temperatura y alcalinidad; consultar la ficha de [pH](../../03_parametros/ph.md) y el [plan de medición](../../../03_pendientes/operacion-recurrente/medicion-y-tests.md).

## Buenas prácticas y límites

- Usar muestra representativa, reactivo dentro de caducidad y el número de gotas especificado; comparar dentro del tiempo y con el fondo/luz prescritos.
- Registrar hora y condiciones comparables: el pH puede variar durante el día. Una lectura puntual no describe amplitud ni tendencia.
- La carta es visual y sus pasos aproximados de 0,2 pH no resuelven variaciones más pequeñas. Si el color cae entre muestras, conservar intervalo o repetir; no inventar decimales.
- El test no identifica por qué cambió el pH ni distingue CO₂ de alcalinidad insuficiente. No usar correctores solo a partir de una lectura.
- No usarlo como sustituto de un electrodo calibrado cuando se requiera serie temporal; los métodos tampoco son intercambiables sin comparación.
- Repetir un resultado discordante y cruzarlo con KH/alcalinidad antes de tomar una decisión relevante.
