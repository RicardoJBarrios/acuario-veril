## Función documentada

Es un adhesivo cementoso de fraguado rápido destinado a unir elementos grandes de roca de acuario. La preparación, el tiempo de trabajo, el curado y las condiciones de uso deben seguir la etiqueta del envase adquirido.

Aquaforest indica que debe mezclarse una pequeña cantidad con agua hasta obtener una consistencia homogénea y utilizarse inmediatamente. El fabricante indica aproximadamente 15 minutos de espera tras unir las piezas. Puede producirse una turbidez temporal y un aumento de pH, especialmente si se fijan varias piezas dentro de un acuario con animales.

## Uso en Veril

Se ha utilizado para fijar las uniones de las rocas del hardscape durante la operación del 5 de septiembre de 2026. La aplicación queda registrada en la [operación de montaje, fijación y primer llenado](../../../04_operaciones/2026/09/2026-09-05-montaje-y-primer-llenado/README.md).

## Preparación y uso

1. Preparar las superficies y estabilizar las piezas antes de mezclarlas
2. Mezclar solo la cantidad que pueda utilizarse durante el tiempo de trabajo
3. Añadir agua hasta obtener una mezcla homogénea, según la etiqueta
4. Aplicar y unir las superficies inmediatamente
5. Mantener las piezas apoyadas durante el fraguado inicial
6. Respetar el tiempo de unión y curado indicado por el envase
7. Retirar el polvo y los residuos sueltos antes de poner el conjunto en servicio

Para una aplicación bajo el agua, Aquaforest indica apagar las bombas de circulación y el retorno. En Veril se utilizó para las uniones del hardscape; la operación concreta queda separada de esta ficha general.

## Límites y riesgos

- La fijación del producto no demuestra por sí sola la estabilidad de toda la estructura
- La cantidad visible, el curado y la resistencia real de cada unión deben comprobarse en la instalación
- No se debe introducir el sistema en una fase posterior hasta respetar las condiciones de curado indicadas por el fabricante
- La turbidez temporal no demuestra que el producto sea inocuo en cualquier cantidad o condición
- Un aumento de pH o la posible liberación de silicatos deben vigilarse si se utiliza una cantidad elevada
- No debe confundirse con AF Poly Glue ni con un cianoacrilato para fijaciones pequeñas
