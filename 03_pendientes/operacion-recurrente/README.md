# Procedimientos recurrentes pendientes de Veril

## Propósito

Esta carpeta reúne procedimientos previstos y repetibles de observación, mantenimiento, registro, ajuste y respuesta a incidencias de Veril. Un procedimiento indica cómo actuar; cada ejecución real se registra por separado en [Operaciones](../../04_operaciones/README.md).

La operación es una capa transversal, no una octava dimensión ni una fase posterior a la maduración. Sus procedimientos utilizan los criterios definidos por las dimensiones y las condiciones concretas documentadas en la [implementación de Veril](../../02_configuracion/README.md).
