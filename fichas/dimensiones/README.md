# Dimensiones arquitectónicas del acuario marino

Esta sección reúne las dimensiones arquitectónicas de referencia adoptadas para Veril. Cada documento desarrolla un eje concreto del sistema y mantiene sus detalles dentro del contenido. Las fichas no sustituyen a los planes de ejecución ni a las fichas propietarias de hardware, parámetros, biología o aquascape.

## Índice

- [Dimensión de procesamiento](dimension-procesamiento.md): basada en el método Berlín, con superficie biológica, circulación, skimmer y exportación
- [Dimensión de comunidad](dimension-comunidad.md): concretada en una configuración mixta de arrecife con peces, corales e invertebrados compatibles
- [Dimensión física](dimension-fisica.md): concretada en un acuario AIO lateral de pequeño volumen, con display, zona técnica, acceso y seguridad
- [Dimensión espacial](dimension-espacial.md): concretada en la organización funcional del aquascape dentro del display
- [Dimensión de iluminación](dimension-iluminacion.md): espectro, intensidad, fotoperiodo, transiciones y luz lunar

## Criterio de lectura

Las fichas describen funciones, límites y relaciones entre componentes. Las decisiones transversales de configuración de Veril se documentan aquí y enlazan con [ciclado y maduración](../../ciclado/README.md), [aquascape](../../aquascape/README.md), las fichas de parámetros y las fichas de hardware correspondientes.
