# Peces

Esta categoría reunirá las fichas generales y específicas de peces marinos relevantes para acuarios de arrecife.

## Responsabilidad documental

Las fichas podrán describir comportamiento, tamaño adulto, alimentación, territorio, compatibilidad, necesidades de espacio y carga biológica. La población concreta, el orden de incorporación y la aceptación en Veril se documentarán fuera de esta categoría.

## Fichas disponibles

Todavía no hay fichas específicas en esta categoría.
