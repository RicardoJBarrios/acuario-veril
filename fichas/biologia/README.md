# Biología del acuario marino

Estas fichas reúnen organismos y procesos biológicos generales relevantes para el funcionamiento y la maduración de un acuario marino. Las decisiones de incorporación específicas se documentan en `veril/` o en el plan operativo correspondiente.

## Índice general

- [Algas](algas/README.md)
- [Microorganismos y microfauna marina](microorganismos/README.md)
- [Cnidarios sésiles](cnidarios-sesiles/README.md)
- [Peces](peces/README.md)
- [Invertebrados](invertebrados/README.md)

Estas categorías organizan las fichas por grupos biológicos y responsabilidad documental. No pretenden sustituir la clasificación taxonómica completa ni crear categorías operativas como «equipo de limpieza» u «organismos beneficiosos».
