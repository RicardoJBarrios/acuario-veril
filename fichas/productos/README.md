## Criterio común

Un producto de arranque no demuestra por sí mismo que un sistema pueda procesar una carga determinada. La capacidad debe verificarse con mediciones y una carga conocida, siguiendo una sola receta coherente.

Las dosis, formatos y condiciones de conservación pueden cambiar. La etiqueta del envase adquirido y la documentación vigente del fabricante prevalecen sobre cualquier resumen.
