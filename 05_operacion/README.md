# Operación de Veril

## Propósito

Esta carpeta reúne los procedimientos definidos de observación, mantenimiento, registro, ajuste y respuesta a incidencias de Veril.

La operación es una capa transversal, no una octava dimensión ni una fase posterior a la maduración. Sus procedimientos utilizan los criterios definidos por las dimensiones y las condiciones concretas documentadas en la [implementación de Veril](../02_veril/00_README.md).

- [Plan de ciclado](../03_ciclado/plan.md): operación específica durante el establecimiento del biofiltro
- [Plan de maduración](../04_maduracion/plan.md): operación específica durante la evolución inicial
