# Operación de Veril

## Propósito

Esta carpeta reunirá los procedimientos recurrentes de observación, mantenimiento, registro, ajuste y respuesta a incidencias de Veril.

La operación es una capa transversal, no una octava dimensión ni una fase posterior a la maduración. Sus procedimientos utilizan los criterios definidos por las dimensiones y las condiciones concretas documentadas en `veril/`.

## Documentación relacionada

- [Modelo de dimensiones](../fichas/dimensiones/modelo.md): criterios que la operación debe observar y evaluar
- [Plan de ciclado](../ciclado/plan.md): operación específica durante el establecimiento del biofiltro
- [Plan de maduración](../maduracion/plan.md): operación específica durante la evolución inicial
- [Implementación de Veril](../veril/README.md): condiciones vigentes del sistema
- [Cambios de agua](cambios-agua.md): preparación, comprobación, registro y contribución del agua nueva

Los procedimientos recurrentes de mantenimiento, seguimiento e incidencias se añadirán aquí cuando estén definidos.
