# Fichas de referencia de Veril

Este directorio reúne fichas de referencia y documentación técnica auxiliar del proyecto: hardware, productos, parámetros del agua, biología, procesos y dimensiones arquitectónicas. Las fichas de organismos contienen conocimiento general reutilizable; las aplicaciones concretas se documentan en la [implementación de Veril](../02_veril/00_README.md) o en los planes operativos correspondientes.

El orden numérico de las categorías propone un recorrido desde el modelo del sistema hasta sus elementos, parámetros y procesos. No implica que todas las fichas deban leerse de forma lineal.

## Índice

- [Dimensiones arquitectónicas](01_dimensiones/00_README.md): procesamiento, biología, infraestructura, espacio, hidráulica, iluminación y química del sistema
- [Biología](02_biologia/README.md): microorganismos, microfauna, algas, cnidarios, peces e invertebrados
- [Parámetros](03_parametros/README.md): parámetros del agua marina
- [Hardware](04_hardware/README.md): urna, equipos, sensores e integraciones
- [Productos](05_productos/README.md): productos documentados
- [Procesos](06_procesos/00_README.md): ciclado, maduración y operación
- [Historia](07_historia/README.md): origen y evolución de métodos y conceptos relevantes
