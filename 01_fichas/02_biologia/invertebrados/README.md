# Invertebrados marinos

Esta categoría reunirá invertebrados marinos que no se documenten en las fichas de cnidarios sésiles ni en las de microorganismos y microfauna.

Puede incluir crustáceos, moluscos, equinodermos, poliquetos, esponjas, tunicados, briozoos y otros invertebrados bentónicos o móviles.

## Responsabilidad documental

Las futuras fichas describirán identidad, función, alimentación, tamaño, comportamiento, compatibilidad, crecimiento y riesgos de mantenimiento. «Equipo de limpieza» no es una categoría biológica: cuando sea relevante, se tratará como una función que pueden desempeñar organismos de varios grupos.
