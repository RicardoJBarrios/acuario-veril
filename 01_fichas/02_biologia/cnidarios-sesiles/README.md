# Cnidarios sésiles

Esta categoría reunirá organismos sésiles o principalmente sésiles del filo Cnidaria que puedan formar parte de un acuario de arrecife. Incluye corales, gorgonias, anémonas, coralimorfarios, zoántidos y otros organismos coraliformes.

## Responsabilidad documental

Las futuras fichas describirán identidad, función, necesidades generales, crecimiento, agresividad, compatibilidad y límites de interpretación. Las decisiones concretas de selección y colocación se documentarán en la [implementación de Veril](../../../02_veril/00_README.md) y en las dimensiones correspondientes.
