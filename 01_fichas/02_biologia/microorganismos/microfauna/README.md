# Microfauna marina

Estas fichas reúnen organismos pequeños asociados a roca, sustrato, biofilms, cristales, refugios y zonas técnicas. Se documentan por función y por grupos reconocibles, sin tratar la microfauna como una comunidad uniforme ni como un equipo de limpieza.
