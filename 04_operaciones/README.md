# Operaciones de Veril

Este directorio es el diario verificable del acuario. Cada entrada registra algo que ocurrió, con su fecha, alcance, resultado, incidencias, evidencia disponible y pendientes derivados.

## Diferencia respecto a las actuaciones pendientes

| Documento | Pregunta que responde | Puede acreditar una ejecución |
| --- | --- | --- |
| [Pendientes](../03_pendientes/README.md) | Qué se pretende hacer y bajo qué condiciones | No |
| Operación | Qué se hizo, cuándo y con qué resultado | Sí, dentro de los límites de su evidencia |
| [Configuración](../02_configuracion/README.md) | Cuál es el estado vigente del acuario | Solo mediante el enlace a la operación que la estableció o comprobó |
| [Verilpedia](../01_verilpedia/README.md) | Qué conocimiento general se utiliza | No |
