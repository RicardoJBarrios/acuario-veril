# Biología específica de Veril

Este directorio reúne la aplicación de las fichas biológicas de Veril: criterios de selección, escenarios, compatibilidades, estados de candidatos y decisiones todavía no ejecutadas. La descripción general de cada organismo pertenece a [Verilpedia](../../01_verilpedia/02_biologia/README.md).

## Orden de lectura

La aplicación biológica de Veril se lee en este orden:

1. [Criterios](01_criterios/README.md): condiciones de selección, bienestar, compatibilidad y carga asumible
2. [Candidatos](02_candidatos/README.md): organismos concretos agrupados por tipo y ordenados por estado
3. [Escenarios](03_escenarios/README.md): combinaciones visuales y secuencias posibles de introducción
