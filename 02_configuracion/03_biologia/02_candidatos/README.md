# Candidatos biológicos para Veril

Este directorio aplica a Veril las fichas generales de la [Verilpedia biológica](../../../01_verilpedia/02_biologia/README.md). Aquí se documentan organismos concretos, su estado actual, el motivo de su consideración, sus restricciones y las comprobaciones pendientes.

## Orden de lectura

Las agrupaciones aparecen por tipo. Dentro de cada una, los organismos se ordenan por estado, desde los más plausibles hasta los descartados provisionalmente:

1. [Algas](algas.md)
2. [Corales y análogos coraliformes](corales-y-analogos.md)
3. [Peces](peces.md)
4. [Invertebrados](invertebrados.md)

El orden de cada ficha es `Candidato`, `Condicional`, `No inicial` y `No propuesto`. Estos estados describen la aplicación a Veril, no la calidad general del organismo ni una incorporación ejecutada.

Las fichas enciclopédicas conservan la información reutilizable sobre identificación, biología, requisitos, compatibilidades, riesgos y fuentes. Si una condición depende de la configuración de Veril, prevalecen estos documentos y los criterios correspondientes. La incorporación efectiva debe registrarse en una [operación](../../../04_operaciones/README.md) y, cuando corresponda, en el plan de maduración u operación recurrente.

Las fichas de microorganismos y microfauna de Verilpedia se mantienen como conocimiento biológico de fondo. No se repiten aquí como candidatos mientras no exista una decisión concreta de incorporación o una aplicación específica a Veril.
