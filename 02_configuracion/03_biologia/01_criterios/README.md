# Criterios biológicos de Veril

Este directorio define cómo valorar organismos para Veril antes de estudiar una combinación concreta. Parte de las fichas generales de [Verilpedia](../../../01_verilpedia/02_biologia/README.md), pero aplica sus requisitos al volumen, la geometría, la madurez, el equipamiento y el mantenimiento de este acuario.

## Documentos

- [Corales](01_corales.md): selección, colocación, crecimiento, luz, flujo y compatibilidad
- [Fauna](02_fauna.md): peces, invertebrados, equipo de limpieza, bienestar y carga biológica

Estos criterios no convierten una especie en candidata ni autorizan una incorporación. La aplicación concreta se documenta en [candidatos](../02_candidatos/README.md), las combinaciones en [escenarios](../03_escenarios/README.md) y las incorporaciones ejecutadas en [Operaciones](../../../04_operaciones/README.md).
