# Unidades biológicas incorporadas a Veril

Este registro identifica los ejemplares observados y los grupos que el propietario comunicó haber inoculado en Veril. Cada unidad tiene un identificador estable `liv-*`; la descripción general de los taxones y productos permanece en Verilpedia, y la ejecución se conserva en el diario de [Operaciones](../../../04_operaciones/README.md).
